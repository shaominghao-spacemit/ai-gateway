## 功能/特性

- U1 管理员完整 unit 的非 root UID 在配置原子替换后仍可读取有效 /etc 配置。
- U2 旧非 root 安装不生成 User=root 或关闭 vendor 安全限制；已有精确错误生成 drop-in 可修复，自定义内容不覆盖。
- U3 acquire 必填独立 recovery_secret，status 公开 owner 不可用于盗 token；相同秘密可恢复丢响应会话。协议 v2。
- U4 并发 SenseVoice 健康检查共用同一探针；有界等待且迟到回复不串包、不误清理正常 worker。
- U5 purge 后外部 ACL 原值及配置恢复源保留在 root 私有 migration-backups/purge-*，新装不当作旧迁移。
- U6 旧 ASR 在 SDK 构造前被拒绝或下载失败不永久阻塞 managed；实际构造失败仍保留锁到进程退出。
- U7 启用鉴权时 GET/HEAD 异步任务结果与音频等数据读取拒绝匿名；健康及静态文档仍公开。
- U8 multipart 解析前按实际累计字节限制（含封装），伪造 Content-Length 不绕过；超限 413、临时文件关闭，解码前有界读取。

## 用户可见行为

- 旧安装升级后仍以原非 root 身份运行，管理员配置可读取，不因包升级被提权或丢失 ACL。
- Voice 使用独立恢复秘密恢复丢失响应的 ASR 会话；公开 owner 无法取得 token，错误秘密返回 403。
- 并发健康检查不会误杀正常后端或串用迟到回复；预检失败后可以重新获取 managed ASR。
- 启用鉴权后匿名 GET/HEAD 数据请求返回 401，健康与静态文档仍可访问；超限上传返回 413。
- purge 后原 ACL、配置和外部数据库可恢复；finally 完成后原包、服务、权限和模型库恢复。
