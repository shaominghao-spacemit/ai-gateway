# Gateway 托管 ASR 与旧客户端升级兼容

任务：task-b15a2812223a40c5；覆盖设计 U4 及 Gateway U8。

## 功能/特性

增量增加 managed status/acquire/release/recognize，托管 SenseVoice/Qwen3 资产校验、推理子进程和资源全寿命；保留旧 ASR 与 LLM/Embedding 接口。默认不开启托管。

## 用户可见行为

Voice 可按 owner/token 获取准确模型和语言能力；HTTP失联不代表释放，失败退出保留锁。升级 Gateway 时旧应用无需变更，既有鉴权选择、模型/DB及调用语义须保持。新安装默认安全配置与升级兼容必须分别检查。

## UI 测试步骤

1. 仅在平台独占租约部署明确SHA256的候选，备份原包、配置、模型元数据与服务；保留旧版Intent原始客户端。
2. 仅升级Gateway包，旧客户端不加key、不改模型配置，执行原版 Intent 实际 Embedding 与 LLM；比对模型ID、语言、grammar与logprobs响应，确认现有用户HOME模型可访问。
3. 通过托管状态确认两模型资产manifest及语言；分别acquire、真实语音识别、release，错误owner/token被拒绝。
4. 固定语言SenseVoice不要求动态setter；请求动态切语言但SDK不支持时明确失败，不静默auto。
5. 注入HTTP取消、父服务退出/子进程仍活、残存未知进程、慢退出，核实kernel flock仍忙且不误杀他方；真实退出后才释放。
6. 使用设备lifecycle脚本并传明确managed-cases进行两模型验收；结束恢复原包与全部服务，核对原数据和权限。
