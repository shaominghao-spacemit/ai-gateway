## UI 测试步骤

1. 旧 Qwen3 endpoint 指向已启动本机引擎，调用旧 models/load，期望成功；managed acquire 仍拒绝接管该端口。
2. 缺少共享锁目录时加载旧模型，期望初始化成功；第二进程无法取得相同 flock，不安全软链/权限拒绝。
3. 托管 Qwen3 先识别真实语音，再发长语音请求；观测独占 slot 从 idle 进入 processing 后暂停其子进程，期望全局 health degraded；release 有界结束，子进程消失后才可取锁，ASR 回到 idle。释放全过程由独立线程每 5ms 检查进程与 flock，子进程存活期间不得解锁。
4. 令启动和首次清理失败，期望 acquire 返回 start_failed，后台重试最终清理；重试期间锁保持占有。
5. 完整管理员 unit 指向旧包配置、停止服务并升级；期望 unit 字节不变，配置兼容入口仍可读。管理员自选配置原样保留。
6. EnvironmentFile 设置自定义 HOME 和 ~/models 路径，停止服务升级；期望模型路径仍以原 HOME 解析。运行进程环境优先。
